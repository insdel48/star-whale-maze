# 阿洛与星鲸 · 迷宫冒险绘本

一个为小朋友和平板触控设计的原创故事迷宫。阿洛要穿过五个形状完全不同的世界，收集散落的星灯，把迷路的小星鲸送回天空。

## 电脑上预览

在这个目录运行一个静态服务器：

```bash
python3 -m http.server 8000
```

然后打开 `http://localhost:8000`。直接双击 `index.html` 也能试玩，但 `file://` 模式不能安装离线 App。

## 带到外面玩

请先把整个文件夹发布到一个支持 HTTPS 的静态网站，再按以下步骤安装：

1. 用 iPad 的 Safari 打开发布后的 `https://...` 地址。
2. 点击 Safari 的“分享”按钮。
3. 选择“添加到主屏幕”。
4. 从主屏幕打开一次游戏，等待页面完整显示。
5. 此后可以断网打开，去公园、坐车或旅行时都能玩。

Android 平板可在浏览器菜单中选择“安装应用”或“添加到主屏幕”。详细说明见 [平板安装说明.md](./平板安装说明.md)。

## 玩法

v31 的故事书架已经有三部可玩绘本：第一部《阿洛与星鲸》、第二部《阿洛与云朵列车》和第三部《阿洛与月光图书馆》分别保存进度，完成后会在首页盖上金色印章。第三部是一张由花园、螺旋书塔、墨水河、猫头鹰钟楼和月亮书库组成的完整大迷宫，三张故事页会依次讲出开头、转折和结尾。

- 在平板上按住阿洛，沿发光边界内的小路连续拖动。游戏采用纯触屏操作，不需要方向键。
- 从地图其他位置开始拖动，可以自由移动画面，回看走过的路线或提前查看后面的区域；松手后画面会停在当前位置。
- 点击顶部的“🔊 朗读”，可以听当前章节、任务和操作提示；故事开头和结尾也有单独的朗读按钮。
- 每一章必须先探索远端岔路、收集三件宝物，才能开启出口。
- 所有故事都使用 Image 2 绘制的完整绘本场景，并把画面里的真实道路逐一转换成可玩的故事迷宫；第三部的月光图书馆拥有 88 个路口和大量环路、纸桥、支路。
- 横屏时每章都会扩展成 4 个探索区域，镜头自动跟随阿洛；右上角小地图可以随时切换完整世界。
- 提供“故事探索者”“勇敢冒险家”“迷宫大师”三档复杂度。
- 五章都使用与插画严格对齐的固定路线；宝物分布在不同区域和岔路，可反复挑战寻找更短走法。
- 三档难度会改变画卷尺寸、线索长度和小地图提示；迷宫大师模式不会在小地图标出宝物。
- 难度、关卡进度和声音设置会自动保存在设备上。
- 不含广告和账号；图片、代码与离线文件都放在游戏文件夹内。
